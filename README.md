# MyDevOpsSkills
Claude DevOps Skills

| Skill | Rôle | Usage |
|---|---|---|
| [devops-skill-interview](devops-skill-interview/SKILL.md) | Architecte Système & Business Analyst | Cadrage du besoin → spécification fonctionnelle et technique |
| [doubt-driven-development](doubt-driven-development/SKILL.md) | Lead Tech sceptique | Décisions techniques justifiées : hypothèses d'échec, alternatives, preuves de viabilité |
| [hostile-review](hostile-review/SKILL.md) | Auditeur Technique Senior | Revue adversariale d'un code, d'une archi ou d'une config → rapport priorisé |
| [cyber-defense](cyber-defense/SKILL.md) | CISO / DevSecOps | Threat model, conformité RGPD/NIS2/DORA → matrice de risques cyber |

## Installation

Copier le dossier d'un skill dans `~/.claude/skills/` (Claude Code) ou l'importer comme skill dans Claude.ai.
